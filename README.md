# Justin Hair Studio

I built this website for my brother's hair studio to make it easier for his clients to book appointments online. I also created a dashboard where he can manage appointments instead of having to handle everything manually.

**Live Website:** https://thecoder237.github.io/JustinHairStudio/

## What It Can Do

* Let clients book appointments online
* Show available dates and times based on the salon's schedule
* Offer different services with different appointment lengths
* Let Justin log in to his dashboard to manage appointments
* Accept, decline, complete, or cancel appointments
* Allow clients to rebook
* Send email notifications for new bookings and appointment updates
* Save appointment information in a database

## What I Used

* HTML, CSS, and JavaScript
* Supabase for the database and login system
* Google Gmail API and OAuth 2.0 for email notifications
* GitHub Pages to host the website
* Git and GitHub to manage the code

## What I Learned

Working on this project helped me learn how to connect a website to a database, set up user authentication, manage appointment information, and get a website published online.

I also got experience troubleshooting issues with Google OAuth and getting email notifications working with a backend function.
